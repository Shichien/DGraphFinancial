# AMLSim Sample Integration Note

## 数据来源

- 仓库：`https://github.com/IBM/AMLSim`
- 目录：`data/amlsim/sample/outputs`

## 当前接入状态

- 已完成账户节点与交易边的解析
- 已映射为当前工程可识别的图二分类输入格式
- 已成功跑通训练命令与提交文件生成逻辑

## 为什么当前结果不能直接对比

样例数据规模非常小，验证划分后容易出现验证集只有单一类别的情况，因此 `ROC AUC` 会变成 `nan`。这并不是代码错误，而是评估样本分布不足。

## 当前价值

- 证明当前架构可以接入第二套公开反洗钱数据
- 为后续接入更大规模 AMLSim 生成数据提供模板
- 可直接用于报告中的 仿真环境 与 系统设计 章节

## 后续建议

- 基于 AMLSim 参数文件生成更大规模样本
- 控制训练/验证划分，确保验证集包含正负两类
- 将更大规模 AMLSim 数据纳入正式多数据集对比实验
