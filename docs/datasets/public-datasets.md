# Public Dataset Integration Plan

本文档说明当前项目基于现有架构可接入的公开数据集，以及各自的落地状态。

## 已接入

- `dgraph_phase1`
  - 本地数据已存在
  - 已打通训练、提交、指标与报告流程
  - 当前最佳验证 AUC 为 `0.832586`
- `dgraph_fin`
  - 已支持直接读取官方 `DGraphFin.zip`
  - 当前验证 AUC 为 `0.828120`
- `dgraph_fin2`
  - 已支持直接读取官方 `DGraphFin2.zip` 并与 `DGraphFin.zip` 自动组合
  - 当前可信验证 AUC 为 `0.827919`
  - 节点时间标签在当前二分类设定下会直接泄漏正类身份，因此默认方案不直接使用该类特征
- `ieee_cis`
  - 已支持直接读取官方 `ieee-fraud-detection.zip`
  - 当前时间切分验证 AUC 为 `0.914582`
  - 适合作为当前统一树模型框架下的强表格基线
- `elliptic_pp`
  - 已支持直接读取当前下载的双 zip 包并自动构造地址级图
  - 修正实现口径后，当前严格复核结果为 `0.926556`
  - 已确认历史实现曾存在时间字段直入特征、伪造边时间戳、验证口径回退到训练段内随机切分等问题
  - 同一地址跨多个 `Time step` 的钱包特征在原始 csv 中完全不变，因此该数据更像全生命周期 actor 分类集，而不是严格因果时序基准
  - 该数据图同配性本身也较强，因此其分数不应直接类比 `DGraph-Fin` 或赛题主数据难度
- `amlsim_sample`
  - 数据来自 `IBM/AMLSim` 仓库自带 sample 输出
  - 已打通数据加载与训练链路
  - 由于样例规模过小、验证折单类，当前不适合作为正式 AUC 对比集

## 已注册待接入

- `ibm_aml`
  - 合成 AML 数据
  - 适合补充仿真环境、系统设计与性能测试

## 当前设计原则

- 不强行把所有数据集压成一种格式
- 图数据走图特征与图模型接口
- 表格数据走通用二分类接口
- 下载受限的数据集先保留规范化入口和说明
- 本地已有数据优先跑通，避免空壳集成
