# 智鉴流盾演示说明

## 演示定位

智鉴流盾面向方向一欺诈交易智能识别，聚焦仿真交易流实时识别、动态图异常检测、风险等级输出和团伙关系溯源。演示材料围绕数据、模型、实时链路、图分析和审计闭环展开，强调算法效果、可信验证和工程可落地性。

## 核心能力

### 识别主链路

系统以 DGraph-Fin 大规模匿名交易关系图作为离线识别主基准，结合图结构统计、交易时间统计、一跳邻居聚合和风险邻域增强形成 126 维特征。模型采用 XGBoost 与 LightGBM 融合，输出账户风险先验，并在实时链路中与行为风险、图团伙风险和规则命中共同形成交易风险分。

### 多数据集验证

当前工程已接入 DGraph-Fin、DGraph-Fin2、IEEE-CIS、Elliptic++ 和 AMLSim 样例，覆盖图交易、时间增强图、表格交易、反洗钱交易网络和仿真交易样例等多种数据形态。

可信验证结果如下：

- DGraph-Fin 可信验证 AUC 为 `0.828120`。
- DGraph-Fin2 移除节点时间标签后，可信验证 AUC 为 `0.827919`。
- IEEE-CIS 采用时间切分，可信验证 AUC 为 `0.914582`。
- Elliptic++ 修正实现口径后，可信验证 AUC 为 `0.926556`。

这些结果说明当前方案不是只适配单一数据集，而是具备跨图数据、时间数据和表格交易数据的迁移能力。

### 可信性控制

系统主动排查数据泄漏和验证口径问题。DGraph-Fin2 移除了会直接暴露正类身份的节点时间标签；IEEE-CIS 从随机切分改为基于交易时间的切分；Elliptic++ 修正了时间字段直入特征、伪造边时间戳和验证口径回退问题。最终保留的是可解释、可复核的可信结果。

### 实时识别闭环

在线链路由多源仿真交易流、Kafka 多主题、Flink 状态特征、模型评分服务、PostgreSQL 风险事件库、Redis 实时榜单、Neo4j 异构关系图和 Vue 大屏组成。交易进入系统后，链路完成特征更新、模型评分、风险分层、风控动作生成、团伙关系追溯和审计记录写入。

### 图分析与溯源

动态图状态服务维护账户、设备、IP 和商户之间的异构关系，输出一跳邻居、二跳组件、风险邻居数、团伙编号和相关节点。图关系不只用于可视化，也参与风险评分和原因解释，支持从单笔交易追溯到团伙结构。

## 演示结构

1. 作品定位：说明方向一任务边界和系统总体目标。
2. 主识别链路：展示 DGraph-Fin 图输入、特征工程、模型融合和风险输出。
3. 实时平台图形摘要：展示多源仿真、实时计算、模型评分、图追溯和审计闭环。
4. 多数据集表现：展示多个公开数据集上的良好结果和验证口径。
5. 实时大屏：展示交易监测、风险评分、告警队列、团伙关系图和复核结果。
6. 工程闭环：展示环境管理、实验记录、部署包、流式原型和审计输出。

## 交付价值

智鉴流盾形成了从离线图交易识别到在线仿真流评分的统一链路。其价值体现在三个方面：第一，识别核心链路具备可复现结果；第二，多数据集验证和反泄漏处理提升了结果可信度；第三，实时大屏、团伙溯源和审计记录支撑从风险识别到人工处置的业务闭环。
