# 实时反诈平台三分钟演示脚本

## 演示目标

用三分钟视频向评委展示：平台能够持续接入交易流，实时生成风险评分，产生告警，追溯团伙图谱，并完成案件处置和审计闭环。

建议打开地址：

```text
http://127.0.0.1:8060
```

## 点击流程

### 1. 打开主页

操作：打开 `http://127.0.0.1:8060`。

等待：约 3 秒。

展示重点：

- 顶部的 Kafka 吞吐和 Flink 延迟。
- 右上角窗口事件数和高危数量。
- 页面数据正在持续刷新。

### 2. 进入总览页

操作：点击左侧 `总览`。

等待：约 5 秒。

展示重点：

- 实时交易监测。
- 风险统计。
- 最近一分钟趋势。
- 欺诈剧本命中榜。

### 3. 进入告警页

操作：

1. 点击左侧 `告警`。
2. 等待约 2 秒。
3. 点击表格中的第一条高危或中危告警。

展示重点：

- 告警工作台支持按等级、渠道、剧本、团伙和状态筛选。
- 点击告警后，可以看到风险分、账户链路、交易渠道、命中剧本和团伙编号。

### 4. 进入案件页

操作：点击左侧 `案件`。

等待：约 2 秒。

展示重点：

- 风险事件编号、源账户、目标账户、交易金额和处置建议。
- 交易链路和关联路径。
- 评分解释。
- 团伙关系证据。
- 原因码。

### 5. 进入图追溯页

操作：

1. 点击左侧 `图追溯`。
2. 等待约 3 秒。
3. 点击左侧团伙列表中的第一项。
4. 点击图谱里的高亮节点。

展示重点：

- 团伙子图会被聚焦。
- 点击节点后，可以查看一跳、二跳关联关系。
- 可以展示共同设备、共同 IP、商户关系等异构证据。

### 6. 进入复核页

操作：

1. 点击左侧 `复核`。
2. 等待约 1 秒。
3. 点击待办列表中的当前高危案件。
4. 点击 `确认欺诈`。
5. 等待约 2 秒。

展示重点：

- 人工处置动作会写入处置记录。
- 审计链路会留下可追溯日志。
- 平台形成从识别到处置的闭环。

### 7. 进入运行页

操作：点击左侧 `运行`。

等待：约 2 秒。

展示重点：

- 交易窗口。
- Kafka 吞吐。
- Flink 延迟。
- 风险统计。
- 欺诈剧本排行榜。
- 实时交易监测。

建议最后停在运行页收尾。

## 三分钟讲稿

大家好，我现在展示的是一个实时反诈风控平台。

首先看总览页。这里的数据不是静态报表，交易流会持续进入系统。上方可以看到当前交易吞吐和实时处理延迟，中间是最近一分钟的趋势变化，右侧和下方会同步刷新实时交易、风险统计和欺诈剧本命中情况。

接下来进入告警页。系统会把实时评分后的中高危事件汇总到告警工作台。这里可以按照风险等级、渠道、剧本、团伙和处置状态筛选。点击一条告警后，右侧会展示这笔交易的风险等级、风险分、交易链路、渠道、剧本和团伙编号。

现在进入案件页。这里是单个风险事件的完整证据链。可以看到事件编号、源账户、目标账户、交易金额和处置建议。下面是交易链路和关联路径，评分解释会拆成离线模型、实时行为、团伙关系和规则命中几部分。再往下是团伙关系证据，包括共用设备账户、同 IP 账户、团伙邻居和原因码。这样评委可以看到系统不是只给一个分数，而是能解释为什么判定它有风险。

接下来进入图追溯页。这里展示的是账户、设备、IP、商户之间的关系图。点击团伙列表中的高风险团伙，图谱会聚焦到相关子图。再点击图上的节点，可以看到一跳、二跳关联关系，以及共同设备、共同 IP、商户关系等异构证据。这部分体现的是风险不是孤立交易，而是团伙网络里的协同行为。

然后进入复核页。这里模拟真实风控人员的处置工作台。左侧是待办案件，中间是当前案件，右侧是审计链路。我点击确认欺诈后，系统会写入处置记录，并在审计链路里留下可追溯日志。这样从实时识别到人工处置形成闭环。

最后进入运行页。这里展示整个平台的运行状态，包括交易窗口、实时吞吐、处理延迟、风险分布和欺诈剧本排行榜。可以看到系统不仅能展示前端图谱，还能持续产生数据、实时计算风险、生成告警并完成审计处置。

这就是我们的实时反诈平台演示。它覆盖了数据流入、实时评分、告警生成、图谱追溯、案件解释和人工处置闭环。

## 时间分配建议

| 时间段 | 页面 | 重点 |
| --- | --- | --- |
| 0:00 - 0:20 | 总览 | 数据持续刷新、吞吐、延迟、趋势 |
| 0:20 - 0:45 | 告警 | 高危事件、筛选、风险分 |
| 0:45 - 1:25 | 案件 | 证据链、评分解释、原因码 |
| 1:25 - 2:05 | 图追溯 | 团伙子图、节点关系、异构证据 |
| 2:05 - 2:35 | 复核 | 确认欺诈、处置记录、审计链路 |
| 2:35 - 3:00 | 运行 | 平台运行指标和总结 |
