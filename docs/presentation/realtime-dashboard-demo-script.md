# 实时反诈平台演示流程

## 演示目标

实时大屏用于呈现仿真交易流进入系统后的完整识别链路，包括交易监测、实时风险评分、告警生成、团伙图谱追溯、案件复核和审计留痕。

演示入口：

```text
http://127.0.0.1:8060
```

## 页面流程

### 总览

总览页展示平台运行状态和实时交易态势。核心观察项包括 Kafka 吞吐、Flink 延迟、窗口事件数、高危事件数、最近一分钟趋势、实时交易列表和欺诈剧本命中情况。

### 告警

告警页汇总实时评分后的中高危风险事件。页面支持按风险等级、交易渠道、欺诈剧本、团伙编号和处置状态筛选。选中风险事件后，详情区展示风险分、风险等级、账户链路、交易渠道、命中剧本和团伙编号。

### 案件

案件页呈现单个风险事件的证据链。内容包括事件编号、源账户、目标账户、交易金额、处置建议、交易链路、关联路径、评分解释、团伙关系证据和原因码。评分解释拆分为离线模型、实时行为、团伙关系和规则命中四类贡献。

### 图追溯

图追溯页展示账户、设备、IP 和商户之间的异构关系。团伙列表用于聚焦高风险子图；节点详情展示一跳、二跳关联关系，以及共同设备、共同 IP 和共同商户等证据。该页面用于说明风险事件不是孤立交易，而是可能处在团伙协同行为中。

### 复核

复核页模拟风控人员处置流程。待办案件、当前案件和审计链路共同构成复核视图。处置动作写入案件记录，并在审计链路中留下可追溯日志。

### 运行

运行页展示平台运行指标，包括交易窗口、Kafka 吞吐、Flink 延迟、风险统计、欺诈剧本排行榜和实时交易监测结果，用于观察系统持续处理交易流的状态。

## 推荐顺序

| 顺序 | 页面 | 核心内容 |
| --- | --- | --- |
| 1 | 总览 | 数据持续刷新、吞吐、延迟、趋势 |
| 2 | 告警 | 高危事件、筛选、风险分 |
| 3 | 案件 | 证据链、评分解释、原因码 |
| 4 | 图追溯 | 团伙子图、节点关系、异构证据 |
| 5 | 复核 | 处置动作、审计链路 |
| 6 | 运行 | 平台运行指标 |

## 核心表达

实时大屏覆盖从数据流入到风险处置的闭环过程。交易事件进入后，系统实时计算特征并完成风险评分；中高危事件进入告警和案件队列；图追溯页面展示团伙关系证据；复核页面记录处置动作和审计日志；运行页面持续呈现吞吐、延迟和风险分布。
