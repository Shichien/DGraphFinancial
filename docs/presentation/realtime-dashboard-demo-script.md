# 智鉴流盾实时大屏视频演示流程与讲稿

## 使用场景

这份脚本用于录制主前端演示视频，建议成片时长控制在 3 分钟左右。演示重点不是逐个介绍按钮，而是展示交易进入、风险识别、告警生成、团伙追溯、人工复核和审计留痕这一条完整闭环。

演示入口：

```text
http://127.0.0.1:8060
```

录制前建议先确认：

- 后端实时服务已启动，页面顶部 Kafka 吞吐和 Flink 延迟有数值。
- 页面处于浅色主题，缩放比例为 100%。
- 从总览页开始录制，左侧导航可见。
- 如需自动走主流程，可以点击顶部演示按钮；如需更稳的节奏，也可以按下面的时间点手动点击页面。

## 三分钟版本

| 时间 | 画面与操作 | 讲稿 |
| --- | --- | --- |
| 0 到 8 秒 | 打开总览页，画面停在顶部品牌、Kafka 吞吐、Flink 延迟和左侧导航。 | 这里展示的是智鉴流盾实时反诈平台的主前端。它把仿真交易流、实时评分、告警处置和团伙追溯集中在一个工作台里，用来说明系统不是只给出一个离线分数，而是能支撑在线识别和人工复核。 |
| 8 到 22 秒 | 保持总览页，镜头关注图谱区域、实时交易监测和当前焦点节点解释。 | 交易进入系统后，前端会持续接收最新快照。左侧图谱展示当前窗口内的账户和关系，右侧交易监测展示最新交易，风险解释区会把当前节点的风险分、风险等级和主要证据同步展示出来。 |
| 22 到 36 秒 | 继续停在总览页，观察实时交易列表刷新，鼠标短暂停在风险解释区。 | 每一笔交易都会结合账户历史风险、实时行为变化、团伙关系和规则命中得到综合风险分。这里的解释不是事后文案，而是由评分服务返回的结构化证据直接驱动。 |
| 36 到 48 秒 | 点击顶部演示按钮，页面出现实时进件、告警出现、图谱追溯、团伙展开、复核写入进度条。 | 为了更清楚地展示主链路，我们启动内置演示流程。它会按真实风控处理顺序依次切换页面，从实时进件开始，一直到复核结果写入审计链路。 |
| 48 到 65 秒 | 页面切到告警，停在告警工作台，展示筛选项和风险事件表格。 | 当风险分达到中高危等级后，事件会进入告警工作台。这里可以按等级、渠道、欺诈剧本、团伙编号和处置状态筛选，风控人员可以快速定位最需要处理的交易。 |
| 65 到 80 秒 | 在告警页选中一条高危或严重事件，右侧案件详情随之变化。 | 选中告警后，右侧立即给出案件摘要，包括风险分、账户链路、交易金额、命中剧本和处置建议。这个页面解决的是告警分拣问题，让人员先判断优先级和处理方向。 |
| 80 到 100 秒 | 切到案件页，展示案件详情、交易链路、评分解释和团伙关系。 | 进入案件页后，可以看到单个风险事件的证据链。系统不仅展示源账户和目标账户，还会列出关联路径、评分拆解、团伙编号、共用设备账户数、同 IP 账户数和原因码，帮助复核人员理解为什么这笔交易被判为高风险。 |
| 100 到 118 秒 | 镜头停在评分解释区域，鼠标轻扫离线模型、实时行为、团伙关系、规则命中等贡献项。 | 评分解释把最终风险分拆成几类贡献。离线模型提供账户风险先验，实时行为反映交易突增和金额异常，团伙关系来自图邻域证据，规则分则对应黑名单、设备复用、商户异常等明确命中项。 |
| 118 到 140 秒 | 切到图追溯页，展示大图、筛选按钮、图例和团伙视图。 | 对反诈来说，单笔交易往往不够。图追溯页把账户、设备、IP、商户这些关系放在一起看，可以从一个告警节点扩展到完整团伙子图，判断它是孤立风险，还是处在协同行为中。 |
| 140 到 156 秒 | 在团伙视图中选择一个团伙，或切换只看团伙、设备复用、IP 聚集、商户洗钱筛选。 | 这里可以按不同风险模式过滤关系，例如设备复用、IP 聚集和商户洗钱。选中团伙后，图谱会聚焦相关节点，右侧同步展示成员数量、总金额、最高风险分和命中剧本。 |
| 156 到 172 秒 | 展示图谱节点详情抽屉或聚焦提示，关注完整邻域数量、相关节点和路径类型。 | 当定位到账户节点后，系统会查询完整邻域，展示一跳和二跳相关关系。资金路径、共同设备、共同 IP 和商户关系会用不同样式区分，这让处置人员能沿着证据链继续追查。 |
| 172 到 190 秒 | 切到控制台，展示交易生成控制台、模板按钮、命令区和模型输出。 | 控制台用于构造测试交易流。我们可以选择低风险单笔、设备复用批次、商户洗钱批次或跨渠道混合场景，直接生成一组交易并提交给评分链路，用来验证系统对不同欺诈模式的响应。 |
| 190 到 208 秒 | 点击设备复用批次或商户洗钱批次，运行后展示模型输出、风险等级统计和单条解释。 | 运行后，右侧会展示本次评分结果，包括每条交易的风险等级、风险分、处置建议和原因码。选中单条结果，还能看到设备、IP、商户、团伙编号以及实时特征，方便检查模型输出是否符合业务预期。 |
| 208 到 232 秒 | 切到复核页，展示待办列表、当前案件、确认欺诈、人工冻结、误报放行按钮。 | 告警进入复核页后，风控人员可以选择当前案件，并执行确认欺诈、人工冻结或误报放行。这个动作会写入案件记录，形成从模型识别到人工处置的闭环。 |
| 232 到 248 秒 | 点击确认欺诈或等待演示流程自动写入，展示处置记录和审计链路新增记录。 | 处置完成后，页面会显示最新处置记录，同时审计链路保留风险判定和人工处置日志。这样后续无论是复盘、申诉还是模型回灌，都有可追溯依据。 |
| 248 到 266 秒 | 切到运行页，展示最近一分钟趋势、风险统计、欺诈剧本、节点排行和实时交易监测。 | 运行页用于观察平台持续处理能力。这里能看到吞吐、延迟、告警数量、模型耗时、欺诈剧本分布和高风险节点排行，证明前端展示的是一个持续运行的实时系统。 |
| 266 到 282 秒 | 切到架构页，展示实时反诈平台技术栈架构图。 | 最后看整体架构。交易从仿真器进入消息队列，经过流式计算生成实时特征，再由评分服务、图状态服务和存储组件共同支撑前端展示，人工复核结果最终回到审计和训练反馈链路。 |
| 282 到 300 秒 | 回到总览页，画面停在图谱和实时交易监测，准备收尾。 | 总结一下，这个主前端展示了智鉴流盾的完整在线能力：交易实时进入，模型实时评分，告警自动分层，图谱追溯团伙，人工复核写入审计。它把离线识别模型和线上风控流程连接成了一个可展示、可复核、可扩展的实时反诈闭环。 |

## 一分钟精简版本

| 时间 | 画面与操作 | 讲稿 |
| --- | --- | --- |
| 0 到 8 秒 | 总览页，展示平台名称、吞吐和延迟。 | 这是智鉴流盾实时反诈平台，前端用于展示交易流进入后的在线识别和处置过程。 |
| 8 到 20 秒 | 总览页，展示图谱、交易监测和解释区。 | 交易进入后，系统实时更新账户关系图、交易列表和风险解释，综合账户先验、实时行为、团伙关系和规则命中输出风险分。 |
| 20 到 32 秒 | 告警页，选中一条高危事件。 | 中高危交易会进入告警工作台，支持按等级、渠道、剧本和团伙筛选，并联动案件详情。 |
| 32 到 44 秒 | 图追溯页，选择团伙或筛选关系。 | 图追溯页把账户、设备、IP 和商户关系放在一起，帮助判断风险事件是否属于团伙协同行为。 |
| 44 到 54 秒 | 复核页，展示处置按钮和审计链路。 | 风控人员可以确认欺诈、人工冻结或误报放行，处置动作会写入案件记录和审计日志。 |
| 54 到 60 秒 | 回到总览页收尾。 | 整个前端完成了实时监测、风险评分、告警分拣、团伙追溯和人工复核闭环。 |

## 录制节奏建议

- 如果视频用于答辩，优先使用三分钟版本，能完整覆盖评分、图追溯和复核闭环。
- 如果视频用于材料附件，使用一分钟版本即可，重点保留总览、告警、图追溯和复核。
- 录屏时不要频繁拖动页面，镜头保持稳定，每个页面停留至少 10 秒。
- 点击演示按钮后，自动流程会依次走实时进件、告警出现、图谱追溯、团伙展开和复核写入，适合录制连续镜头。
- 控制台演示建议只运行一次批次命令，避免多次重置导致画面节奏被打断。

## 页面补充讲解词

### 总览页

总览页是值班人员的第一视角。它同时展示当前交易关系图、最近交易、风险解释和系统状态。通过这个页面可以快速判断交易流是否正常进入、风险事件是否持续出现，以及当前最高风险节点的判定依据。

### 告警页

告警页承担风险事件分拣功能。表格中的每一行代表一条已评分交易，字段包括时间、等级、风险分、账户链路、渠道、命中剧本、团伙和处置状态。筛选项用于把高优先级事件从实时流中快速挑出来。

### 案件页

案件页承担证据汇总功能。它把交易本身、关联路径、评分拆解、团伙关系和原因码放到同一页，避免复核人员只看到一个风险分却不知道原因。这里适合重点讲可解释性。

### 图追溯页

图追溯页承担关系扩展功能。它把资金路径和设备、IP、商户等非资金关系合并展示，并支持按欺诈模式过滤。这个页面适合说明本项目不是孤立判断单笔交易，而是通过图结构追踪团伙风险。

### 控制台页

控制台页承担演示和联调功能。它可以生成低风险单笔、设备复用批次、商户洗钱批次和跨渠道混合等样例交易，提交后直接观察模型输出、原因码和实时特征。

### 复核页

复核页承担人工处置功能。待办列表展示需要处理的高风险案件，当前案件区域给出关键信息，处置按钮写入结果，审计链路记录模型判定和人工动作。

### 运行页

运行页承担运行观测功能。它展示最近一分钟趋势、风险统计、欺诈剧本、风险节点排行和交易监测，用于证明系统处在持续处理状态。

### 架构页

架构页承担整体说明功能。它把仿真接入、消息总线、流式计算、图状态服务、模型评分、告警输出、存储缓存、前端展示和训练反馈闭环放在一张图里，适合作为视频结尾的技术总览。
